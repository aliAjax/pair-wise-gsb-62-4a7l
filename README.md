# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 异常队列、现场复核、证据、复测评估和专业异议并存。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数只读，所有修订形成独立版本和审计时间线。
- JSON审阅包导出。

## 可追溯流程（监测点、读数、阈值版本、异常处置、审阅包共用）

- **阈值草稿提交即冻结**：草稿提交后生成不可改的阈值版本并生效，旧版本废止；冻结时确定受影响读数与异常范围。
- **旧读数保留原判、进入待重算**：历史判定不改写，仅标记待重算；重算完成后原判作为历史版本保留，新判定按新版本盖章。
- **重算去重**：同一异常对同一目标版本只受理一次（去重键 `异常@目标版本`），并发请求拒绝并留痕。
- **断点恢复**：重算按读数逐条推进断点；失败任务保留已处理进度，恢复后从断点继续；已完成任务拒绝按旧版本重放。
- **审批闸门**：审批期间阈值更新即重算受影响异常，按旧依据的方案暂停批准，负责人确认后继续；重算进行中不得批准。
- **审阅包固定版本**：打包携带固定阈值版本、异常关联和未完成重算；重新打开仍按打包时的判据版本解释，不随新版本漂移。
